# Ghost Survival

Survive until the night is over: a dark fantasy survival game for phones.

**Play or install:** https://mehmetrooki.github.io/ghost-survival/

- **Android:** open the link, tap **Download for Android**, then open the downloaded file and tap **Install**.
- **iPhone:** open the link in Safari and tap **Play**. To install it, tap **Share** and choose **Add to Home Screen**.

This repository only holds the built game.

## Türkçe

Gece bitene kadar hayatta kal: telefonlar için karanlık fantastik bir hayatta kalma oyunu.

**Oyna veya kur:** https://mehmetrooki.github.io/ghost-survival/

- **Android:** Linki aç, **Android için indir**'e dokun, sonra inen dosyayı açıp **Yükle**'ye dokun.
- **iPhone:** Linki Safari'de aç ve **Oyna**'ya dokun. Kurmak için **Paylaş**'a dokunup **Ana Ekrana Ekle**'yi seç.

Bu depoda yalnızca oyunun derlenmiş hâli vardır.
